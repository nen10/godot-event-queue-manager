
## 行動解決ターン制

ウェイトターンシステムを参考にしている。行動解決ターン制では、各entityは自分のターン時にAPを消費して行動予約を行い、行動予約は解決されるまでの時間や条件を持つ。自分のターンが来るタイミングは行動予約の一つである"予約準備"によって管理する。


行動予約:

### 基本的な行動予約
- 即時行動:即座に解決される行動予約。(解決時間=0)
- 準備行動:一定の解決時間後に解決される行動予約。(解決時間>0)
- 反応準備:解決時間以外の条件(敵の接近や攻撃など)をトリガーとして解決される行動予約。反応準備は"待機"を解決時に行動予約として付与される。
### 特殊な行動予約
- "待機":消費AP=0,反応準備,<探索>,予約反芻=0
  ターン終了時の反応準備。
  - 自分が予約している行動予約の解決時間の最大値が0であることをトリガーとする。
  - ターン中に選択した反応準備は待機の解決時に行動予約される。
  - 待機の解決時にはさらに、自分自身に"予約準備"を行動予約する。
- "予約準備":消費AP=0,準備行動,<探索>, 解決時間=3 (APが3回復するまでの時間)
  - 解決時、自身はターンを獲得する。
- 操作行動:解決時に、自分自身に限らない対象に行動予約させるような行動予約の分類。
- 予約反芻:解決後に、[反芻カウント>0]ならば、反芻カウントを-1して、行動をもう一度行動予約することを示す、行動予約の分類あるいはパラメータ
- 行動予約の解決:
解決時間が経過して0になる、またはほかの条件によってトリガーされるなどによって、行動予約を解決する。
- 解決時のゲーム進行
  1. 効果をステータスに反映する
  2. 移動や行動の画面エフェクトを反映する
- プレイヤー等が関係する"重要な"行動予約が解決される時
  - プレイヤーの即時行動はプレイヤーターン中の行動選択ごとに解決を行う。ただし、"待機"するまでのプレイヤーターン中は行動選択がロールバックできるようにする。
  - "重要な"行動予約は、その直前の行動予約までの保留中のエフェクトをまとめて処理してから画面エフェクトを反映する。
- プレイヤーが関与しない行動予約だが、感知範囲内にかかわる行動予約が解決される時
  - 効果のステータス反映は解決のたびに随時行う。
  - 画面エフェクト反映は保留し、プレイヤーターン開始時に保留中のエフェクトをまとめて処理する。
    (※表示上の矛盾を防ぐ):行動予約内容が、移動したentityを対象にするとき、エフェクトの位置とentityの位置が整合しない可能性がある。
    そのため、移動済みの対象を参照する行動予約を解決する時は、その直前の行動予約までの保留中のエフェクトをまとめて処理してから、以降の保留中のエフェクトを処理する。
- 感知範囲外で完結する行動予約が解決される時
  - 効果のステータス反映は解決のたびに随時行う。
  - 画面エフェクト反映はスキップする。
- 予約される行動の例:
- "移動" : 自身が移動範囲内を移動する。消費AP=3,即時行動,<探索>
- "即時攻撃" : 自身が対象のHPにダメージを与える。消費AP=2,即時行動,<損害>
- "準備攻撃" : 一定時間後に、選択した地点範囲について対象のHPにダメージを与える。消費AP=4,準備行動,<損害>,解決時間=3
- "反撃準備" : 自身を対象とする<損害>タイプの行動予約が解決された時をトリガーとする。自身がその主体のHPにダメージを与える。消費AP=1,反応準備,<損害>,予約反芻=1,持続時間=3
